## Python 기본

| 용어 | 쉽게 말하면 | 짧은 예 |
|---|---|---|
| 코드 | 컴퓨터에게 시키는 명령을 적은 글 | `print("hi")` |
| 변수 | 값에 붙인 이름표 | `age = 20` |
| 문자열 | 따옴표로 감싼 글자 데이터 | `"Seoul"` |
| 숫자형 | 계산할 수 있는 숫자 | `10`, `3.14` |
| 리스트 | 여러 값을 순서대로 담은 상자 | `[10, 20, 30]` |
| 딕셔너리 | 이름과 값을 짝으로 담은 상자 | `{"age": 20}` |
| 함수 | 입력을 받아 일을 하는 작은 기계 | `print(...)` |
| 매개변수 | 함수에 넣어 주는 값이나 설정 | `head(3)`의 `3` |
| 반환값 | 함수가 일을 마치고 돌려주는 결과 | `mean()`의 평균값 |
| 메서드 | 어떤 값이나 표가 가지고 있는 함수 | `df.head()` |
| 라이브러리 | 다른 사람이 만들어 둔 도구 모음 | Pandas, Matplotlib |
| import | 라이브러리를 현재 코드로 가져오기 | `import pandas` |
| 셀 | Notebook에서 글이나 코드를 담는 네모 칸 | 코드 셀, 설명 셀 |

## 데이터 표

| 용어 | 쉽게 말하면 | 짧은 예 |
|---|---|---|
| Series | 표에서 열 하나처럼 생긴 1차원 데이터 | `df["age"]` |
| DataFrame | 행과 열로 된 전체 표 | `df` |
| 행(row) | 한 사람, 한 집처럼 관측 대상 하나의 정보 | 가로 한 줄 |
| 열(column) | 이름, 나이처럼 같은 종류의 값 모음 | 세로 한 줄 |
| index | 각 행에 붙은 이름표 | `0, 1, 2` |
| 자료형(dtype) | 그 열이 숫자인지 글자인지 나타내는 종류 | `int64`, `object` |
| 결측값 | 값이 비어 있거나 모르는 상태 | `NaN`, `None` |
| 조건 | 값이 원하는 기준에 맞는지 묻는 식 | `age >= 20` |
| 불리언 | 참/거짓 값 | `True`, `False` |
| 마스크 | 각 행이 조건에 맞는지 적은 참/거짓 목록 | `df["age"] >= 20` |
| 필터링 | 조건에 맞는 행만 고르기 | `df.loc[mask]` |
| 집계 | 여러 값을 하나의 요약값으로 계산 | 합계, 평균, 개수 |
| 그룹화 | 같은 값끼리 묶은 뒤 집계 | `groupby("JOB")` |
| 병합 | 공통 열을 기준으로 두 표를 연결 | `merge` |
| 파생 열 | 기존 열을 계산해 새로 만든 열 | 월급 × 12 = 연봉 |

## 머신러닝

| 용어 | 쉽게 말하면 | 짧은 예 |
|---|---|---|
| 특성(feature), `X` | 문제를 풀 때 컴퓨터가 보는 힌트 | 방 개수, 범죄율 |
| 타깃(target), `y` | 컴퓨터가 맞혀야 하는 정답 | 주택 가격 |
| 모델 | 데이터에서 규칙을 배우는 계산 방법 | 선형회귀 |
| 학습, `fit` | 연습 데이터로 규칙을 찾는 과정 | `model.fit(...)` |
| 예측, `predict` | 배운 규칙으로 새 답을 계산 | `model.predict(...)` |
| train 데이터 | 모델이 규칙을 배우는 연습 문제 | 보통 전체의 70~80% |
| test 데이터 | 학습 후 실력을 재는 마지막 시험 | 보통 전체의 20~30% |
| 평가 지표 | 예측을 얼마나 잘했는지 나타내는 숫자 | RMSE |
| 전처리 | 학습 전에 빈값·글자·숫자 범위를 정리 | 결측 대치, 스케일링 |
| 인코딩 | 글자로 된 범주를 숫자로 바꾸기 | 서울/부산 → 0/1 열 |
| 스케일링 | 열마다 크게 다른 숫자 범위를 맞추기 | 평균 0, 표준편차 1 |
| 데이터 누수 | 시험 정보를 학습 중에 미리 보는 실수 | test 평균으로 결측 채우기 |
| 타깃 누수 | 정답 또는 정답으로 만든 값을 입력 특성에 넣는 실수 | `TAX / MEDV`를 입력으로 사용 |
| EDA | 모델 전에 분포·관계·이상한 값을 탐색하는 과정 | 히스토그램, `describe` |
| 상관계수 | 두 숫자가 함께 움직이는 방향과 정도 | `-1`부터 `1` |
| 다중공선성 | 입력 특성끼리 너무 비슷하게 움직이는 상태 | `RAD`와 `TAX` |
| VIF | 한 특성이 다른 입력 특성으로 얼마나 설명되는지 보는 수치 | 다중공선성 점검 |
| 이상치 | 다른 값에서 멀리 떨어져 확인이 필요한 관측치 | IQR 경계 밖 값 |
| 잔차 | 실제값에서 모델 예측값을 뺀 차이 | `y - prediction` |
| 레버리지 | 입력 특성 공간에서 다른 행과 멀리 떨어진 정도 | 특이한 X 조합 |
| Cook's distance | 한 행이 회귀 결과 전체를 얼마나 바꾸는지 보는 수치 | 영향력 있는 점 점검 |
| 왜도 | 분포가 왼쪽이나 오른쪽으로 치우친 정도 | 양수면 오른쪽 꼬리 |
| 첨도 | 분포 꼬리와 극단값의 정도 | Pandas 정규분포 기준 `0` |
| 로그 변환 | 큰 양수를 압축해 긴 꼬리를 줄이는 변환 | `np.log(x)` |
| Pipeline | 전처리와 모델 순서를 한 묶음으로 관리 | scaler → PCA → model |
| PCA | 여러 수치 열의 정보를 더 적은 새 축으로 요약 | 13개 특성을 12개 성분으로 |
| 공분산 | 두 숫자가 같은 방향으로 변하는 정도 | PCA 공분산 행렬 |
| 고유벡터 | PCA가 찾은 새로운 축의 방향 | PC1 방향 |
| 고유값 | 해당 주성분 축이 담는 분산의 크기 | 큰 값부터 선택 |
| 설명 분산 비율 | 전체 분산 중 주성분 하나가 보존한 비율 | PC1 60% |
| 교차검증 | 학습 데이터를 여러 번 나누어 성능을 반복 측정 | 5-fold CV |
| 과적합 | 학습 데이터는 잘 맞지만 새 데이터 성능이 낮은 상태 | 복잡한 파생 특성 남용 |
| 회귀 | 연속적인 숫자를 예측 | 가격 예측 |
| 분류 | 정해진 종류를 예측 | 정상/불량 |
| 군집 | 정답 없이 비슷한 것끼리 묶기 | 고객 그룹 찾기 |

## 기호 빠르게 찾기

| 기호 | 뜻 |
|---|---|
| `=` | 오른쪽 값을 왼쪽 이름에 저장 |
| `==` | 두 값이 같은지 질문 |
| `>=`, `<=` | 크거나 같은지, 작거나 같은지 질문 |
| `&` | 두 조건이 모두 참 |
| `|` | 두 조건 중 하나 이상 참 |
| `~` | 참과 거짓을 반대로 |
| `:` | 슬라이스 범위 또는 코드 블록의 시작 |
| `.` | 앞의 대상이 가진 기능이나 속성 사용 |
| `#` | 실행하지 않는 설명 메모 |
