이 문서는 Python을 처음 보는 사람을 위한 준비 수업입니다. 여기 있는 코드를 모두 외울 필요는 없습니다.

## 1. 우리가 사용하는 프로그램은 무엇인가요?

수업 파일의 확장자는 `.ipynb`입니다. 이것은 **Jupyter LAB(Notebook)** 파일입니다.

Notebook은 설명 글, Python 코드, 실행 결과를 한 화면에 차례로 담을 수 있는 전자 공책입니다.

```text
설명 셀      오늘은 표를 읽어 봅니다.
코드 셀      print("안녕하세요")
실행 결과    안녕하세요
```

- 네모난 칸 하나를 **셀(cell)**이라고 합니다.
- 코드 셀을 클릭하고 `Shift + Enter`를 누르면 실행됩니다.
- `In [ ]`가 `In [1]`처럼 숫자로 바뀌면 실행된 것입니다.
- 셀 왼쪽의 실행 버튼 `▶`을 눌러도 됩니다.

## 2. 첫 코드 실행하기

새 코드 셀에 다음을 입력하고 `Shift + Enter`를 누릅니다.

```python
print("안녕하세요")
```

예상 결과:

```text
안녕하세요
```

`print`는 괄호 안의 내용을 화면에 보여주는 기능입니다. 따옴표 안의 글자는 컴퓨터가 계산하지 않고 글자 그대로 다룹니다.

## 3. 변수는 이름표가 붙은 상자입니다

```python
age = 20
name = "Kim"

print(age)
print(name)
```

이 줄을 다음처럼 읽습니다.

```text
age = 20       → 20이라는 값에 age라는 이름표를 붙인다
name = "Kim"   → Kim이라는 글자에 name이라는 이름표를 붙인다
```

Python에서 `=`은 수학의 “양쪽이 같다”보다 **오른쪽 값을 왼쪽 이름에 저장한다**는 뜻입니다.

## 4. 자주 보게 될 괄호

| 모양 | 초보자용 뜻 | 예 |
|---|---|---|
| `()` | 기능을 실행하거나 필요한 값을 전달 | `print("hi")` |
| `[]` | 여러 값을 담거나 표의 일부를 선택 | `[10, 20, 30]`, `df["age"]` |
| `{}` | 이름과 값을 한 쌍으로 저장 | `{"name": "Kim"}` |
| `" "` 또는 `' '` | 글자임을 표시 | `"Seoul"` |
| `#` | (주석)실행하지 않는 메모 | `# 이름 출력` |

## 5. 함수와 메서드

**함수**는 미리 만들어 둔 작은 작업 기계입니다.

```python
print("hello")
```

`print` 기계에 `"hello"`를 넣어 화면에 출력한 것입니다.

점(`.`) 앞에 대상이 있으면 보통 그 대상이 가진 **메서드**입니다.

```python
df.head()
```

“DataFrame `df`가 가진 `head` 기능을 실행해 앞부분을 보여 달라”고 읽습니다.

## 6. 라이브러리와 import

모든 기능을 직접 만들지 않고 다른 사람이 잘 만들어 둔 도구 모음을 가져다 씁니다. 이 도구 모음이 **라이브러리**입니다.

```python
import pandas as pd
```

한 조각씩 읽으면 다음 뜻입니다.

```text
import pandas    → pandas 도구 모음을 가져온다
as pd            → 앞으로 pandas를 짧게 pd라고 부른다
```

그래서 `pd.read_csv(...)`는 “Pandas가 가진 CSV 읽기 기능”입니다.

## 7. 오류는 고장이 아니라 안내문입니다

오류가 나오면 다음 순서로 봅니다.

1. 빨간 글자의 **마지막 줄**을 먼저 읽습니다.
2. `NameError`: 이름을 만들지 않았거나 철자가 다릅니다.
3. `FileNotFoundError`: 파일 경로 또는 이름이 다릅니다.
4. `ModuleNotFoundError`: 라이브러리가 설치되지 않았습니다.
5. `SyntaxError`: 괄호, 따옴표, 쉼표가 빠졌는지 확인합니다.
6. 고친 뒤 오류가 난 셀부터 다시 실행합니다.

오류가 나오는 것은 학습이 잘못된 것이 아니라 컴퓨터가 이해하지 못한 위치를 알려주는 과정입니다.

## 8. 첫 30분 실습

아래를 순서대로 실행합니다.

```python
import pandas as pd

students = pd.DataFrame({
    "name": ["Kim", "Lee", "Park"],
    "score": [80, 95, 70],
})

students
```

예상 결과:

| index | name | score |
|---:|---|---:|
| 0 | Kim | 80 |
| 1 | Lee | 95 |
| 2 | Park | 70 |

다음 셀도 실행합니다.

```python
students["name"]
```

이 코드는 학생 표에서 `name` 열 하나를 꺼냅니다.

```python
students["score"].mean()
```

이 코드는 점수 열의 평균을 계산합니다. 결과는 약 `81.67`입니다.
